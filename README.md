# Yettel Integration Developer Task

This is my solution for the Integration Developer test

## Setup 

### Prerequisites 

- Docker
- Docker Compose

### Project Setup

1. Clone the repository: 

```
git clone https://github.com/sarabene/integration-developer.git
``` 

2. Build and start services 
```
docker-compose up --build
```

3. Access the application: 

- API: `http://localhost:8080`
- Documentation: `http://localhost:8080/api-docs`
